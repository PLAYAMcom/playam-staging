Current implementation snapshot

Staging foundation present: Friendship Court, Would You Rather, Truth or Dare, Mind Battle and Secret Confessions have database game keys and Starter question content. There are 100 active Starter questions, 20 per mode.

Not yet implemented as playable Staging modes: sports/traditional games, Cotton Ball Challenge, LIVE Q&A, Scoreboard, Legend and combat/action games including CODs.

This is a roadmap, not a release announcement. Each game will be added and tested without replacing the existing five modes.

Shared gameplay targets

  • Mobile-first, with web/PC support planned.
  • Solo vs computer, private multiplayer and LIVE broadcasting where suitable.
  • Difficulty options designed per game; very easy / normal / hard considered as a common pattern.
  • Snooker intended for LIVE and offline play.
  • CODs remains free-to-play, with no pay-to-win advantages.
  • Fair play, player safety, moderation and account security throughout.

Development sequence

  1. Protect and finish the foundation: validate existing Staging games, Report Player, account security and multiplayer flows.
  2. Complete existing social games: polish and test the five current modes without breaking them.
  3. Build sports/traditional games: define rules and controls, then implement and test one at a time.
  4. Build combat foundation: networking, matchmaking, movement, maps, fairness and moderation; Team Deathmatch first.
  5. Expand combat modes: Tactical 5v5, Zombie Survival, Survival Extraction and Battle Royale incrementally; CODs stays its separate design track.
  6. Expand LIVE and social play: LIVE Q&A, suitable LIVE game modes, Scoreboard and Legend.
  7. Quality checks: gameplay, accessibility, abuse prevention, device performance and real multiplayer tests before release.

A game moves to “In development”, “Testing” or “Released” only after code and verification support that status.
